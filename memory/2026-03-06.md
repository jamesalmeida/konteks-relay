### Railway Restart Fix
- **Old `serviceInstanceRedeploy` mutation was deprecated/removed** — Railway API silently returned success without doing anything
- New Railway API uses deployment-based mutations:
  - `deploymentRestart(id)` — restarts container, no new deployment in history
  - `deploymentRedeploy(id)` — creates new deployment from same image (visible in Railway dashboard)
- Flow now: query latest deployment for service+environment → call `deploymentRedeploy` on it
- Two subscriptions had stale `instanceStatus: "restarting"` from old broken code — manually patched to "running" via temp Convex mutation

### Key Learnings (Evening)
- Railway API changes silently — old mutations return success without error even when deprecated
- `internalMutation` in Convex can only be called from other Convex functions, NOT from HTTP clients
- Always verify Railway actions by checking deployment history, not just API response
