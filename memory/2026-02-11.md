### Bug Fixes
- **Vercel preview deploys failing** — `NEXT_PUBLIC_CONVEX_URL` env var was only scoped to Production, not Preview. James fixed in Vercel settings.
- **Site down after merge** — Convex functions weren't deployed to prod. Need to run `npx convex deploy --yes` after merging Convex changes. This happened twice today.
- **Admin panel errors** — Codex used `requireAdmin()` (Convex auth) but admin page uses hardcoded password auth. Removed Convex auth from testimonial functions. Created issue #29 to properly secure admin with Convex auth later.
- **Testimonial card layout** — Fixed responsive grid (4→3→2→1 columns), removed X badge, fixed card height/spacing.

### Key Learnings
- **Convex deploy is a separate step** — Merging code to main and deploying to Vercel does NOT deploy Convex functions. Must run `npx convex deploy` separately.
- **Admin auth mismatch** — The admin page uses a client-side password (`planets-mgm-TEMPER`), not Convex auth. Any Convex functions called from admin can't use `requireAdmin()` pattern. Issue #29 tracks fixing this.
- **Vercel env var scoping** — Environment variables can be scoped to Production/Preview/Development. Preview deploys won't get Production-only vars.
