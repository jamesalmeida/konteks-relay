## Issue #144: Google Meet Integration via OpenUtter
- OpenUtter (github.com/sumansid/openutter) — headless Google Meet bot for OpenClaw
- Joins meetings, captures live captions, takes screenshots
- **Architecture decisions:**
  - Guest mode (bot joins as separate participant) is the right default — user joins normally too
  - Auth mode (joins as user's account) would block user from joining — worse for notetaker use case
  - Available on **all tiers** — James's pricing philosophy: only paywall things that cost him money (LLM models)
  - Pre-install Chromium/Playwright in Docker image for everyone — enables many other skills beyond just Meet
- **Future: Auto-join from calendar** — cron scans Google Calendar for Meet links, creates one-shot cron jobs to auto-join at meeting time
- Chromium/Playwright adds ~400MB to Docker image but unlocks web browsing, screenshots, form filling for any skill
