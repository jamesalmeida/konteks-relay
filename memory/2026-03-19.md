### Relay Protocol Fix (Big Debugging Session)
- The konteks-relay script was using an outdated OpenClaw gateway WebSocket protocol
- Gateway now requires protocol v3 with: `{ type: "req", method: "connect", params: { minProtocol: 3, maxProtocol: 3, client: {...}, auth: {...}, device: {...} } }`
- Device identity required for operator scopes — without it, scopes get cleared (`clearUnboundScopes`)
- Signature payload is v3 format: `v3|deviceId|clientId|clientMode|role|scopes|signedAtMs|token|nonce|platform|deviceFamily`
- Public key must be base64url-encoded raw 32-byte ed25519 key (not full SPKI DER)
- Device ID = SHA-256 hex of raw key bytes
- `chat.send` params changed: uses `message` field (not `text`)
- Agent responses are streaming frames: `stream: "assistant"` with `data.text` (accumulated) and `data.delta` (incremental), completed by `stream: "lifecycle"` with `phase: "end"`
- Relay now accumulates streaming text and pushes complete response to Convex on lifecycle end
