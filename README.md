# 🐙 Tersono

**Tersono** (E.H. Tersono) is an [OpenClaw](https://github.com/openclaw/openclaw) AI agent workspace — a Culture drone named after the character from Iain M. Banks' *Look to Windward*.

## What Is This?

This repo backs up Tersono's workspace files — identity, memory, configuration, and installed skills. It's the persistent state that lets Tersono wake up each session knowing who it is and what it's been working on.

## Who Is Tersono?

Tersono is the primary AI agent managed by James Almeida. It runs on a Mac Mini (M4, 32GB, 2TB) in the garage and handles:

- 💼 **Business operations** — IAS consulting, Sheldn.ai, project management
- 💻 **Coding** — Spawning Codex sessions, PR reviews, repo management
- 📧 **Communications** — Email monitoring, WhatsApp, Discord, Telegram
- 🏠 **Home automation** — Home Assistant via REST API
- 📊 **Finance** — Investment tracking, tax planning
- 🔍 **Research** — Web search, content summarization, X/Twitter monitoring
- 📝 **Productivity** — Calendar, Things 3, Obsidian notes
- 🤖 **Content** — YouTube summarization, social media management
